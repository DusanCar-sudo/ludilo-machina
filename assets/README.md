# Ludilo Machina logo

`ludilo-machina-logo-terminal.png` is the terminal-first app mark: terminal
brackets around a machine core. It is transparent RGBA and intended for dark
Termux surfaces; it also works as a single-colour mark.

For plain-text CLI output, use the compatible compact mark:

```text
<o>
```

Keep CLI banners monochrome and let the terminal theme provide the colour.
