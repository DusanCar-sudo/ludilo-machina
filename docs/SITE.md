# The website

Live at https://dusancar-sudo.github.io/ludilo-machina/ , served from `site/` by GitHub Pages.

- One static page: `site/index.html`, no build step, no third-party requests. Fonts are in `site/fonts/`.
- Deploy: push to `main`. `.github/workflows/pages.yml` publishes `site/` when anything under it changes.
- Pictures in `site/img/` are real phone screenshots (Redmi Note 12 Pro). Status bars were checked: time, battery, signal only.
- Social card: `site/og.jpg` (1200x630).
- Claims on the page come from this repo only. Verified on one phone; no license file yet, so the page does not state one.
